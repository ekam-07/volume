How to get everyone connected

Same Wi-Fi — best case. Lowest latency, nothing to set up.

No Wi-Fi? Turn on the host phone's hotspot and have everyone join that. It works fully offline and is just as tight.

Everyone on mobile data? Deploy this server to the internet and phones can join from anywhere — the song is downloaded before it plays, so the network isn't in the audio path.

Bluetooth can't do this: phones can't act as Bluetooth speakers for each other, and its 100–200 ms variable latency is far too loose to sound like one source.
